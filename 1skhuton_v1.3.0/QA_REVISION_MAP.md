## 미반영(선택) 항목
- 범위 밖 여부를 응답 필드로 받아 프론트에서 안내하는 방식은 API 계약 변경이 필요해 적용하지 않았습니다.
  현재는 선택지(1개)와 안내 문구로 개발 관련 질문 입력을 유도합니다.

## 확인이 필요한 항목
- 맞춤법의 "인증 세션" 항목: 기술 용어 session의 표준 표기는 "세션"이라 프롬프트에 "세션"을 올바른 표기로 반영했습니다.
  QA 표의 방향(세션 → 섹션)이 반대라면 알려 주세요. E-2는 "문제없음"에도 포함되어 있어 확인이 필요합니다.
