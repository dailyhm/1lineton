# 추가 확보가 필요한 파일

이 ZIP에는 아래 3개 파일이 포함되어 있지 않습니다. 현재 포함된 `evaluations/test_cases.json`은 v1.1.0 평가 사례 6개이며, 요청한 R7/R6 파일을 대신하는 것으로 간주하면 안 됩니다.

## 1. `R7_demo_dataset_v1.3.0.json`
- 프로젝트의 R7 데모 데이터셋 원본을 관리하는 저장소/공유 드라이브/작성자에게서 v1.3.0 태그 또는 커밋과 함께 받아야 합니다.
- 단순히 `evaluations/test_cases.json`의 파일명을 바꾸면 안 됩니다. 데이터 구조와 버전, 데이터 출처를 확인하세요.

## 2. `R6_input_output_samples.json`
- R6 단계에서 실제 입력과 출력의 쌍을 수집한 원본 파일이 필요합니다.
- R6 실행 로그, 실험 결과 폴더, 팀 공유 드라이브 또는 해당 데이터를 생성한 담당자에게 요청하세요.
- API 키, 토큰, 개인정보 등 민감정보를 제거한 뒤 JSON 유효성과 입력-출력 짝의 일치 여부를 검증하세요.

## 3. `collect_r6_live_samples.py`
- R6 실시간 샘플 수집을 수행한 원본 Python 스크립트입니다. 이 ZIP에는 스크립트나 해당 스크립트의 저장소 주소가 없습니다.
- Git 저장소가 있다면 `git log --all -- collect_r6_live_samples.py` 및 `git ls-files '*collect_r6_live_samples.py'`로 이력/추적 여부를 확인하고, 원격 저장소의 R6 브랜치·태그에서도 검색하세요.
- 없으면 R6 수집 담당자에게 원본 스크립트와 실행 방법, 사용한 환경변수, 출력 경로를 요청해야 합니다. 목적만 보고 새로 작성한 스크립트는 원본 확보와 구분해 관리하세요.

파일을 받으면 파일명뿐 아니라 버전/생성일/출처와 데이터 스키마를 함께 확인한 후 프로젝트에 추가하세요.
